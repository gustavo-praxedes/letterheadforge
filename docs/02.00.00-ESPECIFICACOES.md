# LetterheadForge — Especificação v0.1.0

Aplicação web estática para configurar folhas A4, A5 ou A6 com pauta, moldura, marca d'água, imagens e caixas de texto, e exportar um PDF vetorial em A4 pronto para impressão doméstica.

- Repositório: `https://github.com/gustavo-praxedes/letterheadforge`
- Publicação: `https://gustavo-praxedes.github.io/letterheadforge/`
- Licença: MIT, Gustavo Praxedes, 2026
- Idioma da documentação: pt-BR. Código, identificadores e commits: inglês.
- Referências `(Rnn)` indicam a pergunta numerada do processo de levantamento em que a decisão foi tomada. Referências `(Pnn)` indicam premissas adotadas pela spec, listadas no Apêndice A para revisão.

---

## 1. Visão geral

### 1.1 Objetivo

Permitir que a pessoa configure visualmente uma folha de escrita (papel timbrado, caderno, cartão pautado) e baixe um PDF em A4 contendo 1 página A4, 2 páginas A5 ou 4 páginas A6, todas com a mesma configuração (R2).

### 1.2 Princípios

1. Todo o processamento ocorre no navegador. Sem backend, sem telemetria, sem cookies, sem envio de dados (R27, R118).
2. Uma única descrição da cena (`Scene`) alimenta o preview e o PDF. O que se vê é o que se imprime.
3. Nada fixo no código: cores e tipografia da interface em `tokens.css`; textos em `strings.pt-BR.js`; números, limites e tolerâncias em `config.js`; dados de fontes, modelos e paleta em `data/`.
4. O núcleo geométrico é puro (sem DOM) e testável em Node.
5. Nenhuma falha silenciosa. Todo erro gera aviso visível (R124).
6. Interface minimalista, tema claro, acessível (WCAG AA).

### 1.3 Fora de escopo da v1

CMYK; zoom e pan no preview; pinça no mobile; modo offline/PWA; hifenização; texto rico (estilos por trecho); recorte e espelhamento de imagem; tema escuro; interface multilíngue (as strings ficam isoladas para tradução futura); guias manuais e réguas; marca d'água em mosaico; verso ou frente e verso; backend; mais de uma marca d'água por página; páginas com configurações diferentes entre si.

### 1.4 Navegadores e dispositivos

Versões atuais de Chrome, Edge, Firefox e Safari (R62). Desktop e mobile (R30). EyeDropper API apenas onde existir.

## 2. Modelo de dados

Unidades internas: milímetros em ponto flutuante, origem no canto superior esquerdo da página. Conversão para pontos (1 pt = 25,4/72 mm) somente na camada do PDF.

```json
  "name": "Meu papel timbrado",
  "page": {
    "size": "A4",
    "orientation": "portrait",
    "color": "#FFFFFF",
    "margins": { "top": 10, "right": 10, "bottom": 10, "left": 10 }
  },
  "frame": {
    "enabled": true,
    "color": "#3A3A3AFF",
    "thickness": 0.5,
    "style": "solid",
    "doubleGap": 1.0,
    "cornerRadius": 5
  },
  "ruling": {
    "enabled": true,
    "type": "lines",
    "color": "#C8C8C8FF",
    "thickness": 0.25,
    "style": "solid",
    "dotRadius": 0.3,
    "insets": { "top": 5, "right": 5, "bottom": 5, "left": 5 },
    "objectDistance": 5,
    "x": { "mode": "spacing", "spacing": 8, "count": 20 },
    "y": { "mode": "spacing", "spacing": 8, "count": 30 }
  },
  "watermark": {
    "enabled": false,
    "kind": "text",
    "text": { "content": "", "fontId": "inter", "weight": 400, "italic": false, "sizePt": 48, "color": "#000000", "align": "center", "lineHeight": 1.2 },

    "x": 0, "y": 0, "w": 0, "h": 0,
    "rotation": 0,
    "opacity": 0.15
  },
  "objects": []

```

Valores acima correspondem à configuração inicial (R104, R115): A4, retrato, folha branca, margens de 10 mm, moldura sólida de 0,5 mm em cinza escuro com raio de canto de 5 mm, pauta horizontal com espaçamento de 8 mm em cinza claro de 0,25 mm, distância pauta-moldura de 5 mm nos quatro lados, sem marca d'água e sem objetos.

### 2.2 Campos

| Campo | Tipo | Valores / limites |
|---|---|---|
| `page.size` | enum | `A4`, `A5`, `A6` |
| `page.orientation` | enum | `portrait`, `landscape` |
| `page.color` | cor | `#RRGGBB`, sempre opaca (R137) |
| `page.margins.*` | número | 0 a `limits.marginMax`; área útil mínima de `limits.minContentSize` |
| `frame.style` | enum | `solid`, `dashed`, `dotted`, `dashdot`, `double` (R148) |
| `frame.cornerRadius` | número | 0 até metade do menor lado da moldura (limitado automaticamente) |
| `ruling.type` | enum | `lines` (horizontais), `grid` (quadriculada), `dots` (grade de pontos) (R11) |
| `ruling.style` | enum | `solid`, `dashed`, `dotted`, `dashdot` (R72). Não se aplica a `dots`. |
| `ruling.insets.*` | número | Distância individual da pauta até a moldura (ou até a margem, sem moldura) (R13, R69) |
| `ruling.objectDistance` | número | Distância única da pauta até imagens e caixas de texto (R39) |
| `ruling.x`, `ruling.y` | objeto | Cada eixo escolhe o próprio modo: `spacing` (quantidade automática) ou `count` (espaçamento automático) (R10, R74). Em `lines`, só `y` é usado. |
| `*.color` (pauta, moldura) | cor | `#RRGGBBAA`, alfa permitido (R132) |

Todos os mínimos e máximos numéricos residem em `config.js` (`limits`).

### 2.3 Objetos

Ordem do array = ordem de empilhamento entre objetos (último fica por cima).

```json
{
  "id": "uuid-v4",
  "type": "image",
  "name": "Logotipo",
  "x": 20, "y": 15, "w": 40, "h": 20,
  "rotation": 0,
  "visible": true,
  "locked": false,
  "imageId": "uuid-v4",
  "opacity": 1,
  "aspectLocked": true
}
```

```json
{
  "id": "uuid-v4",
  "type": "text",
  "name": "Endereço",
  "x": 20, "y": 250, "w": 80, "h": 20,
  "rotation": 0,
  "visible": true,
  "locked": false,
  "text": "Rua Exemplo, 100",
  "fontId": "inter", "weight": 400, "italic": false,
  "sizePt": 10, "color": "#222222",
  "align": "left", "lineHeight": 1.3,
  "background": "#FFFFFF00",
  "border": { "color": "#000000FF", "thickness": 0 },

```

- `x`, `y`, `w`, `h` descrevem o retângulo sem rotação. A rotação é em graus, de −180 a 180, em torno do centro do retângulo (R55).
- Máximos por preset: 3 imagens (R111), 10 caixas de texto (P5), 30 presets nomeados (R123).
- `align`: `left`, `center`, `right`, `justify` (R103).
- Imagens ficam em armazenamento separado (`images`), referenciadas por `imageId`, para não pesar o histórico de desfazer.


Envelope: `{ "app": "letterheadforge", "appVersion": "0.1.0", "schemaVersion": 1, "preset": {...}, "images": [...] }`. Imagens em base64. Migrações por versão em `core/migrate.js`.

## 3. Folha A4 e marcas de corte

### 3.1 Tamanhos nominais

| Tamanho | Retrato (mm) | Paisagem (mm) |
|---|---|---|
| A4 | 210 × 297 | 297 × 210 |
| A5 | 148 × 210 | 210 × 148 |
| A6 | 105 × 148 | 148 × 105 |

Valores em `config.js` (`paperSizes`).

### 3.2 Montagem

A orientação da A4 é derivada da página (R33). Páginas mantêm o tamanho nominal. A folga de 1 mm restante é distribuída igualmente nas duas pontas do eixo (0,5 mm).

| Página | Orientação da A4 | Grade | Células |
|---|---|---|---|
| A4 retrato / paisagem | igual à página | 1 × 1 | 1 |
| A5 retrato | paisagem | 2 colunas × 1 | 2 |
| A5 paisagem | retrato | 1 coluna × 2 | 2 |
| A6 retrato | retrato | 2 × 2 | 4 |
| A6 paisagem | paisagem | 2 × 2 | 4 |

Função pura `layoutSheet(size, orientation)` retorna `{ sheet: {w, h}, cells: [{x, y, w, h}], dividers: [...] }`. A cor da folha preenche toda a A4.

### 3.3 Margens e moldura

- As margens (quatro valores individuais) são aplicadas por página pequena (R4).
- A moldura é um retângulo recuado das bordas da página pelas margens. A moldura é a borda ao redor da pauta (R9).
- Margem inferior a 5 mm: aviso visível no campo (limite doméstico de impressão), sem bloqueio. Valor 0 é permitido (R32).
- A moldura é contínua e desenhada acima dos objetos. Objetos não a cortam (R43, R140).
- Tipo `double`: dois traços de `thickness` separados por `doubleGap`, simétricos em relação ao retângulo.

### 3.4 Marcas de corte

Apenas em A5 e A6 (R3). Cor igual à da pauta, mesmo com a pauta desligada (R71). Espessura fixa de 0,25 mm em `config.js` (R88).

**Posição (R114):** traços curtos nas duas extremidades de cada divisão, sobre a linha de divisão, na borda da A4; em A6, também quatro traços no cruzamento central, um em cada direção.

**Comprimento (R113, R129):** cada traço usa `min(cutMarkLength, margem do lado em que se estende)`, com `cutMarkLength = 3 mm` em `config.js`. Margem 0 nesse lado: sem traço (R98). Margens assimétricas geram marcas assimétricas.

| Traço | Margem usada |
|---|---|
| Divisão vertical, extremidade superior | `top` |
| Divisão vertical, extremidade inferior | `bottom` |
| Divisão horizontal, extremidade esquerda | `left` |
| Divisão horizontal, extremidade direita | `right` |
| Cruzamento, para a esquerda | `right` (página à esquerda) |
| Cruzamento, para a direita | `left` (página à direita) |
| Cruzamento, para cima | `bottom` (página acima) |
| Cruzamento, para baixo | `top` (página abaixo) |

Marcas são geradas pela função pura `cutMarks(layout, margins)` e entram na `Scene` como linhas contínuas. O preview da página configurada não as exibe. O preview da A4 montada as exibe.

## 4. Motor da pauta

Módulo `core/ruling.js`, puro, sem DOM.

### 4.1 Área da pauta

- Com moldura: retângulo da moldura recuado por `insets` (individuais).
- Sem moldura: retângulo da margem recuado por `insets` (R69).
- Se a área tiver largura ou altura inferior a `limits.minRulingArea`, a pauta não é gerada e um aviso é exibido.

Observação: com `insets` iguais a 0 e moldura ligada, a primeira e a última linha coincidem com a moldura e ficam sob ela (R37, P1).

### 4.2 Posições das linhas

Para cada eixo, sobre um comprimento útil `L` da área:

- **Modo quantidade (`count = n`, n ≥ 2):** espaçamento = `L / (n − 1)`. A primeira linha fica no limite inicial e a última no final.
- **Modo espaçamento (`spacing = s`):** `n = floor(L / s) + 1`; resto `r = L − (n − 1) · s` dividido igualmente entre o início e o fim: a primeira linha fica em `r / 2` (R99).

A grade quadriculada e a grade de pontos aplicam a mesma regra nos dois eixos, resultando em grade centralizada em X e Y (R86, R100). Cada eixo escolhe o próprio modo (R74).

### 4.3 Tipos

| Tipo | Elementos |
|---|---|
| `lines` | Segmentos horizontais na largura da área |
| `grid` | Segmentos horizontais e verticais |
| `dots` | Pontos circulares de raio `dotRadius` nas interseções |

### 4.4 Estilos de traço (R72, R141)

Padrões definidos em `config.js` como múltiplos da espessura, multiplicados por um fator de escala configurável (`strokeScale`, padrão 1,0):

| Estilo | Padrão (traço, intervalo, ...) em múltiplos da espessura | Terminação |
|---|---|---|
| `solid` | — | reta |
| `dashed` | 4, 3 | reta |
| `dotted` | 0, 3 | redonda (ponto de diâmetro igual à espessura) |
| `dashdot` | 6, 3, 0, 3 | redonda nos pontos, reta nos traços |

O mesmo mecanismo vale para a moldura. A fase do padrão inicia no começo de cada segmento.

### 4.5 Zonas bloqueadas por objetos

Objetos visíveis (R146) bloqueiam a pauta, ocultos não. Objetos bloqueados (cadeado) também bloqueiam (R147). A marca d'água não bloqueia (R19). A moldura não é cortada (R43).

**Imagem — silhueta real (R14):**

1. A imagem é rasterizada, com posição, tamanho e rotação, em uma máscara de alfa na resolução `limits.maskResolution` = 4 px/mm (precisão de 0,25 mm, R87).
2. Pixel é opaco quando alfa ≥ `limits.alphaThreshold` = 10% (R41).
3. Buracos internos são preenchidos: preenchimento por inundação a partir da borda do retângulo envolvente; pixels não alcançados passam a opacos (R40).
4. Dilatação euclidiana (transformada de distância exata) por `objectDistance`.
5. Imagem sem canal alfa gera retângulo completo (R46).

**Caixa de texto (R16, R77):** retângulo rotacionado completo, mesmo com fundo transparente, dilatado por `objectDistance`.

**Interface testável:** `buildBlockMask({ objects, alphaMasks, sheetCell, config }) → Mask`. A extração de alfa (canvas) fica fora do núcleo; o núcleo recebe `{ width, height, data: Uint8Array }`.

### 4.6 Corte de linhas

1. Para cada linha, amostrar a máscara a cada 0,25 mm e obter os intervalos livres.
2. Linhas que sofreram ao menos um corte: descartar trechos menores que `limits.minSegment` = 15 mm (R42). Linhas sem corte são mantidas integralmente.
3. As linhas continuam depois do objeto (R15).
4. Grade de pontos: o ponto é omitido se o seu disco tocar a máscara bloqueada. Não há trecho mínimo (R86).

### 4.7 Saída

`buildRuling(preset, layoutCell, blockMask) → { segments: [{x1,y1,x2,y2}], dots: [{cx,cy,r}], warnings: [] }`.

## 5. Objetos, camadas e edição

### 5.1 Ordem de camadas (R140)

Da base ao topo, fixa: folha, marca d'água, pauta, objetos (na ordem do painel), moldura.

### 5.2 Imagens

- Formatos: PNG, JPG, WebP (R46). A detecção usa os bytes iniciais do arquivo, não a extensão.
- WebP é convertido para PNG sem perdas na importação, pois a biblioteca de PDF não incorpora WebP (P4).
- Limites: lado maior até 3508 px e arquivo até 25 MB (R82). Máximo de 3 imagens por preset, 75 MB no total (R111). A imagem da marca d'água fica fora da contagem de 3, mas respeita 25 MB e 3508 px (R112).
- Arquivo acima de 25 MB: rejeitado, sem reamostragem (R121).
- Lado maior acima de 3508 px: rejeitado com mensagem, oferecendo reamostragem com proporção travada e qualidade alta (R102, R120). A reamostragem só é oferecida se o arquivo original não exceder 25 MB.
- Aviso quando a resolução efetiva no tamanho posicionado for inferior a `limits.minEffectivePpi` = 150 ppi (R83).
- No PDF, a imagem original é incorporada sem recompressão (R47).
- Controles: posição, tamanho (proporção travada por padrão), rotação, opacidade, ordem, ocultar, bloquear, duplicar, excluir (R18, R21, R50). Crop e espelhamento ficam fora da v1 (R139).

### 5.3 Caixa de texto

- Estilo único por caixa (R23). Campos: texto, fonte, peso, itálico, tamanho (pt), cor do texto, alinhamento, entrelinhas, cor de fundo com alfa, borda (cor e espessura), rotação (R24, R54, R55).
- Tamanho de fonte de 4 a 200 pt (P6).
- Quebra de linha por palavras; sem hifenização (R116). Palavra maior que a largura é quebrada por caractere.
- Texto excedente é cortado no retângulo da caixa, com indicador visual de excesso no preview e aviso na lista de camadas (R53).
- A medição e a quebra de linha usam as métricas da própria fonte carregada (fontkit), as mesmas no preview e no PDF.

### 5.4 Marca d'água (R17, R18, R44, R45, R76)

- Uma por preset, replicada em todas as páginas. Fixa no fundo, fora do painel de camadas, editada em seção própria.
- Tipo texto (mesmos controles da caixa de texto, exceto fundo e borda) ou imagem.
- Controles: posição, tamanho, rotação, opacidade. A opacidade é o alfa da marca d'água; o seletor de cor da marca de texto não exibe barra de alfa (P7).
- Tamanho inicial de texto 48 pt; de imagem, 50% da largura da área da página.

### 5.5 Posicionamento

- Objetos podem ser posicionados livremente, inclusive parcialmente fora da página; o excedente é cortado no limite da página no preview e no PDF (R75). A lista de camadas indica objetos totalmente fora da página.
- Ao trocar tamanho ou orientação da página, objetos mantêm a posição em mm a partir do canto superior esquerdo (R125, R126).

### 5.6 Snap e guias (R22, R48, R138)

- Guias automáticas durante arrasto, redimensionamento e movimentação por teclado.
- Alvos: bordas e centros da página; bordas das margens; bordas e centro da moldura; limites da área da pauta; posições das linhas da pauta; bordas e centros dos outros objetos.
- Tolerância `config.snap.toleranceMm` = 2 mm. Segurar Alt desativa o snap.
- Rotação: com Shift, passos de 15° (R78).
- Guias aparecem apenas no preview, nunca no PDF.

### 5.7 Painel de camadas (R50)

Lista única de imagens e caixas de texto, com: reordenar (arrastar e botões frente/trás), ocultar, bloquear, duplicar, excluir, renomear. Objeto bloqueado não pode ser movido nem redimensionado, mas continua no PDF e bloqueando a pauta.

### 5.8 Desfazer e atalhos (R51, R127)

Histórico de 100 passos (`limits.historySize`). Interações contínuas (arrasto, digitação) geram um passo ao terminar.

| Atalho | Ação |
|---|---|
| Ctrl/Cmd+Z | Desfazer |
| Ctrl/Cmd+Shift+Z ou Ctrl+Y | Refazer |
| Ctrl/Cmd+D | Duplicar objeto |
| Ctrl/Cmd+S | Salvar preset |
| Delete / Backspace | Excluir objeto selecionado |
| Setas | Mover 1 mm (`config.keyboard.nudgeMm`) |
| Shift+Setas | Mover 10 mm (`config.keyboard.nudgeShiftMm`) |
| Alt (segurado) | Desativar snap |
| Shift (segurado ao rotacionar) | Passos de 15° |
| Esc | Limpar seleção |
| `?` | Painel de atalhos |

Atalhos são ignorados quando o foco está em campo de texto, exceto Ctrl/Cmd+Z, +S.

## 6. Seletor de cor

Componente próprio, sem biblioteca (R130), em `ui/color-picker.js`.

- Área de saturação e brilho, barra de matiz, barra de alfa (somente onde permitido), campos HEX e RGB (R134).
- HEX aceita `#RGB`, `#RRGGBB` e `#RRGGBBAA`.
- Alfa permitido: linhas, pontos, moldura, fundo e borda da caixa de texto. Não permitido: cor da folha (R137), cor do texto, marca d'água (usa controle de opacidade) (P7).
- Amostras: paleta em `data/palette.json` (P8) mais as 8 últimas cores usadas, salvas no navegador (R133).
- Conta-gotas via EyeDropper API quando disponível; oculto nos demais (R131).
- Acessível: área SV operável por setas (passo 1%, Shift 10%), barras como `role="slider"` com `aria-valuenow`, anúncio do valor HEX.
- Cor no PDF: RGB, sem conversão para CMYK (R135). Sem aviso de cor escura (R136).

## 7. Fontes e bibliotecas

### 7.1 Fontes

- Origem: Fontsource via jsDelivr, com versão fixa por fonte, o mesmo arquivo na tela e no PDF (R89).
- Subconjuntos: `latin` e `latin-ext` (R90). Cada caractere usa a primeira fonte do conjunto que possuir o glifo; `latin-ext` é carregado apenas quando necessário.
- Catálogo: `data/fonts.json`, gerado pelo script `scripts/build-fonts-manifest.mjs` a partir da API pública do Fontsource e versionado no repositório. Campos: `id`, `family`, `category`, `weights`, `styles`, `subsets`, `version`. Sem chave de API (R56).
- Seletor: lista curta de 15 fontes no topo mais busca em todo o catálogo, com filtro por categoria (R25).

Lista curta (R142): Inter, Roboto, Open Sans, Lato, Montserrat, Poppins, Playfair Display, Merriweather, Lora, Oswald, Roboto Mono, Dancing Script, Caveat, Pacifico, Great Vibes.

Modelo de URL (em `config.js`): `https://cdn.jsdelivr.net/fontsource/fonts/{id}@{version}/{subset}-{weight}-{style}.woff`.

**Formato do arquivo (decisão de 2026-11-23, ver `docs/02.01.00-DECISOES.md` §3):** `WOFF`, não `WOFF2`. O `@pdf-lib/fontkit` lê WOFF2, mas o subconjunto (`subset: true`) falha com `RangeError` em fonte Inter `latin`, e a exceção nasce dentro de um `setTimeout`, fora do alcance de `try/catch`. Com WOFF a leitura, a medida e o subconjunto funcionam e o PDF A4 de uma página fica em cerca de 6,5 KB com três fontes incorporadas. O `version` da URL é o `npmVersion` do pacote `@fontsource/*` (5.3.0 na data), não o campo `version` da API do Fontsource.

- Carregamento: `fetch` do arquivo uma vez, mantido em cache em memória; usado em `new FontFace()` para o preview e em `fontkit.create()` para medida e para o PDF.
- Peso e itálico oferecidos apenas se existirem na fonte (R54).
- Falha ao baixar uma fonte usada: aviso visível e exportação bloqueada (R81).
- Caractere sem glifo em nenhum subconjunto: aviso visível e exportação bloqueada até a remoção do caractere (P3).
- Fonte da interface: Inter, servida pelo mesmo mecanismo (Fontsource/jsDelivr) para manter o escopo de rede declarado (P2).
- Fontes são licenciadas sob SIL OFL; o README informa a atribuição.

### 7.2 Bibliotecas em `vendor/` (R91)

| Biblioteca | Uso | Licença |
|---|---|---|
| pdf-lib | Geração do PDF | MIT |
| @pdf-lib/fontkit | Fontes, métricas e subconjuntos | MIT |

Versões fixas, cópias das distribuições minificadas, com arquivo `vendor/VERSIONS.md` (nome, versão, origem, SHA-256, licença). Nenhuma biblioteca de runtime é carregada de CDN. A compatibilidade do fontkit com WOFF2 é validada no marco 1 (Apêndice B).

## 8. Exportação PDF

### 8.1 Arquitetura

- `Scene` (lista de primitivas em mm) → renderizador SVG (preview) e renderizador PDF (exportação).
- Primitivas: `rect` (com raio), `line` (com estilo de traço), `dot`, `image` (com transformação e opacidade), `textRun` (palavras posicionadas), `clip`.
- Geração em Web Worker, com mensagens de progresso por etapa e cancelamento por `terminate()` (R143).

### 8.2 Etapas e validação

1. Validação: fontes carregadas, glifos presentes, limites de imagens, margens, preset válido. Qualquer erro bloqueante interrompe com aviso (R81, P3).
2. Carregamento e incorporação de fontes (subconjunto).
3. Máscaras de bloqueio e pauta.
4. Montagem da cena por célula da A4.
5. Renderização no PDF.
6. Serialização e download.

### 8.3 Características do PDF

- Uma página A4 na orientação derivada; 595,276 × 841,890 pt em retrato.
- Vetorial: texto como texto com fontes incorporadas em subconjunto; linhas e pontos como traçados. Imagens originais incorporadas (R26, R47).
- Espaço de cor RGB.
- Recorte do conteúdo de cada célula (página) para cortar objetos que ultrapassam o limite (R75).
- Recorte do texto ao retângulo da caixa e rotação aplicada por matriz.
- Metadados: título `LetterheadForge — {nome do preset}`, produtor `LetterheadForge {versão}`, criador `LetterheadForge`, data de criação (R106).
- Nome do arquivo: `letterheadforge-{a4|a5|a6}-{retrato|paisagem}-{AAAAMMDD}.pdf` (R105).
- Sem aviso na exportação. Aviso fixo e simples abaixo do preview: imprimir em 100% (tamanho real), sem ajustar à página (R36).

### 9.2 Regras

- Autosave do rascunho com debounce de `config.autosaveMs` = 1000 ms (R128).
- Presets nomeados: máximo 30, nome único, até 60 caracteres (P5, R123). Duplicidade pede novo nome.
- Modelos prontos são somente leitura. O usuário salva uma cópia como novo preset. Um modelo não pode ser sobrescrito (R79).
- Modelos: caderno pautado, quadriculado, pontilhado, caligrafia e em branco (R68). Parâmetros em `data/templates.json`. "Caligrafia" usa pauta horizontal com espaçamento próprio, sem tipo dedicado (P9).
- Cota excedida (`QuotaExceededError`) ou falha de escrita: aviso visível sugerindo exportar JSON (R124). Solicitar `navigator.storage.persist()` na primeira gravação.
- Exportar e importar JSON com imagens embutidas (R60). A importação valida o esquema, os limites de imagens (R82, R111), o MIME por bytes iniciais, e rejeita o arquivo inteiro com mensagem clara em caso de violação (R122). Nenhum conteúdo importado é executado ou inserido como HTML.
- Ao abrir, restaura o rascunho; se não existir, aplica a configuração inicial da seção 2.1.

## 10. Interface, acessibilidade e atalhos

### 10.1 Layout

- Desktop: painel de configuração à esquerda (seções recolhíveis: Folha, Margens, Moldura, Pauta, Marca d'água, Objetos e camadas) e preview à direita.
- Cabeçalho: nome do produto, menu de presets (modelos, abrir, salvar, salvar cópia, exportar/importar JSON), botão Exportar PDF.

- Aviso de impressão abaixo do preview (R36).
- Mobile: abas Configuração e Preview; arrasto por toque; tamanho por alças e campos numéricos (R63).

### 10.2 Campos numéricos (R145, R49)

Aceitam vírgula e ponto na digitação e exibem vírgula (pt-BR). Campos numéricos para posição, tamanho e rotação dos objetos, além do arrasto. Valores fora do intervalo são ajustados ao limite com aviso associado ao campo.

### 10.3 Visual

- Tema claro (R64). Cinzas neutros com um único acento (R65). Tipografia Inter (P2).
- `src/styles/tokens.css`: cores, espaçamentos, raios, sombras, tipografia, camadas (z-index), durações, tamanhos de alvo de toque.
- `src/styles/base.css` e `components.css` usam apenas tokens.
- Strings em `src/strings.pt-BR.js`, organizadas por área, sem texto fixo nos componentes (R31).

### 10.3 Acessibilidade (R110)

- WCAG 2.1 AA: contraste de texto ≥ 4,5:1 e de componentes ≥ 3:1; foco visível; alvos de toque ≥ 44 px no mobile.
- Toda função disponível por teclado, incluindo seleção e movimento de objetos pela lista de camadas e setas.
- Rótulos e papéis ARIA em controles, painéis, alertas (`role="alert"` para avisos e erros) e no seletor de cor.
- Preview SVG com `role="img"` e descrição textual resumida; os objetos são operáveis pela lista de camadas.
- Respeita `prefers-reduced-motion`.

### 10.4 Avisos (catálogo)

### 10.5 Segurança e privacidade

- Sem telemetria, cookies ou envio de dados. Único tráfego externo: download das fontes pelo jsDelivr. Declarado no README (R118).

## 12. Marcos, critérios de aceite e testes

Ordem de implementação (R149).

### Marco 1 — Núcleo geométrico e testes

Entregáveis: `units`, `layout`, `cutmarks`, `strokes`, `mask`, `ruling`, `scene`, `snap`, `text-layout`, `schema`, `validate`, `config.js`. Spike de fontkit com WOFF2.

Critérios de aceite:
- Todos os testes da matriz abaixo passam em Node, sem DOM.
- Nenhum número de regra fora de `config.js`.
- Spike confirma o carregamento de WOFF2 no fontkit, ou decide o fallback (Apêndice B).

### Marco 2 — Interface e preview

Entregáveis: layout responsivo, painéis, seletor de cor, camadas, edição com snap, atalhos, desfazer, avisos, renderizador SVG, carregamento de fontes.

Critérios de aceite:
- O preview reflete qualquer alteração de configuração em menos de 150 ms para um preset típico (1 imagem, 3 caixas).
- Todos os atalhos da seção 5.8 funcionam; painel `?` os lista.
- Navegação por teclado completa; contraste AA verificado.
- Mobile: arrasto de objetos e abas funcionam.

### Marco 3 — Exportação PDF

Entregáveis: renderizador PDF, worker, progresso e cancelamento, validações bloqueantes.

Critérios de aceite:
- PDF A4 com 1, 2 ou 4 páginas conforme o tamanho, texto selecionável e fontes incorporadas.
- Medidas conferidas com régua digital: tolerância de 0,2 mm sobre as dimensões.
- Pauta, moldura e objetos idênticos ao preview da A4 montada.
- Cancelar interrompe o worker sem baixar arquivo.
- Falha de fonte e glifo ausente bloqueiam a exportação com aviso.

### Marco 4 — Presets e dados

Entregáveis: IndexedDB, autosave, presets, modelos, JSON, tratamento de cota.

Critérios de aceite:
- Recarregar a página restaura o rascunho com imagens.
- Exportar e importar JSON reproduz o preset sem perdas.
- Importação acima dos limites é rejeitada com mensagem clara.
- Cota excedida gera aviso com sugestão de exportação.
- Modelos não são sobrescritos.

### Marco 5 — Repositório e CI

Entregáveis: README, AGENTS.md, LICENSE, workflows, `.versionrc.json`, `vendor/VERSIONS.md`, comandos de publicação.

Critérios de aceite:
- `npm ci && npm test` verde no CI.
- Publicação no Pages acessível pela URL do projeto.
- `npm run release -- --first-release` gera a tag `v0.1.0`.

### 12.1 Matriz de testes do núcleo

| Módulo | Casos obrigatórios |
|---|---|
| `layout` | Seis combinações de tamanho e orientação; folga de 0,5 mm distribuída; células sem sobreposição; divisões corretas |

## Apêndice A — Premissas para revisão

| Id | Premissa |
|---|---|
| P1 | A primeira e a última linha ficam nos limites da área da pauta (moldura ou margem recuada por `insets`). Só ficam sob a moldura quando `insets` = 0. |
| P2 | A fonte da interface (Inter) é servida pelo Fontsource/jsDelivr, e não pela API do Google Fonts, para manter a declaração de privacidade do R118. |
| P3 | Caractere sem glifo bloqueia a exportação, de forma coerente com o R81. |
| P4 | WebP é convertido para PNG sem perdas na importação, pois a pdf-lib não incorpora WebP. |
| P5 | Até 10 caixas de texto por preset; nomes de preset únicos com até 60 caracteres; padding inicial de 2 mm nas caixas. |
| P6 | Tamanho de fonte de 4 a 200 pt; rotação de −180 a 180. |
| P7 | Marca d'água usa apenas o controle de opacidade; o seletor da cor do texto da marca não tem alfa. |
| P8 | A paleta predefinida fica em `data/palette.json`, e as cores e tipografia da interface em `tokens.css`. |
| P9 | O modelo "caligrafia" é pauta horizontal com espaçamento próprio, sem tipo dedicado. |
| P10 | Distância aos objetos inicia em 5 mm, igual às distâncias iniciais da moldura. |
| P11 | Pinça e zoom ficam para a v2; no mobile, a v1 oferece arrasto, alças e campos numéricos. |
| P12 | Trecho mínimo de 15 mm só é aplicado a linhas que sofreram corte por objeto. |

## Apêndice B — Riscos

| Risco | Mitigação |
|---|---|
| fontkit pode não ler WOFF2 | Spike no marco 1; fallback: converter para WOFF ou TTF no script de manifesto, ou usar arquivos WOFF do Fontsource |
| Memória no mobile com imagens grandes | Limites de 3 imagens e 3508 px; máscaras em 4 px/mm; descartar bitmaps após extração de alfa |
| Divergência entre preview e PDF | Cena única; mesma quebra de linha e mesmas métricas; teste visual manual do marco 3 |
| Impressoras domésticas sem área de impressão nas bordas | Aviso de margem < 5 mm; marcas de corte limitadas à margem |
| Disponibilidade do jsDelivr | Mensagem clara de falha; exportação bloqueada apenas para fontes ausentes |
| Cota do IndexedDB | Limites por preset; aviso e exportação JSON; `storage.persist()` |
| Desempenho da máscara em A4 | Resolução de 4 px/mm (≈ 1 Mpx); cache por objeto; recálculo com debounce |
