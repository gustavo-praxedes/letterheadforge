## 2. Regras fixadas na execução

| Id | Decisão | Origem |
|---|---|---|
| D1 | `"1.000"` é rejeitado por ambiguidade (separador de milhar), código `units.ambiguousNumber`. | plano §5.1 |
| D2 | Estilo `dashdot` usa terminação redonda em todo o traçado (limitação de `stroke-linecap` uniforme). | plano §5.3 |
| D3 | Dilatação da máscara cresce exatamente `objectDistance * maskResolution` pixels, medida pela borda do objeto. | plano §5.6 |
| D4 | Entrelinha calculada como `ptToMm(sizePt) * lineHeight`; linha de base em 80% do tamanho da fonte a partir do topo da linha. | contratos §11 |
| D5 | `spacing > length` na pauta produz uma única linha centralizada em `length / 2`. | plano §5.7 |
| D6 | Máscara de bloqueio é montada por célula, em coordenadas locais, resolução de 4 px/mm. | contratos §9 |
| D7 | Limites numéricos escolhidos: `marginMax` 50 mm, `minContentSize` 30 mm, `minRulingArea` 5 mm, espessura de moldura 0,1–5 mm, espessura de pauta 0,05–2 mm, espaçamento 0,5–100 mm, quantidade 2–200. | contratos §1 |
| D8 | `scene` exige `measure` quando há texto; ausência é erro de programação (`TypeError`), não erro de usuário. | contratos §12 |
| D9 | Lint com ESLint 9 flat config; sem regra de formatação. | diretrizes §2 |
| D10 | Prints para o agente de revisão visual são gerados por Playwright em `temp/shots/`. | diretrizes §2 |
