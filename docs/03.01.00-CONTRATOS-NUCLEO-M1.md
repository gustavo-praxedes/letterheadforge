# Contratos do núcleo — Marco 1

Documento de referência para todos os executores do Marco 1. Ele fixa **nomes de export, formatos de dados e códigos de erro**. Não substitui a spec: em caso de dúvida de comportamento, vale `docs/02.00.00-ESPECIFICACOES.md`; em caso de dúvida de interface, vale este documento. Divergência entre implementações é defeito, mesmo que os testes locais passem.

## 0. Regras comuns a todos os módulos

1. Módulos ES puros em `src/core/`. Sem `window`, `document`, `fetch`, sem `node:*` (exceto em `src/store/history.js`, que também é puro). Nenhuma dependência de runtime.
2. Unidade interna: milímetros em ponto flutuante. Origem no canto superior esquerdo. Nunca converter para pontos fora de `units.js`.
3. Entrada inválida do usuário **nunca** gera exceção: retorna objeto com `ok: false` e `code` em string. Exceção só para erro de programação (argumento obrigatório ausente).
4. Determinismo: mesma entrada → mesma saída, inclusive ordem de arrays. Nada de `Date`, `Math.random`, `crypto` fora de `schema.uuid()`.
5. Nenhum número de regra no código: todo limite vem de `src/config.js`. Tolerância numérica: `config.epsilon`.
6. Testes em `tests/core/<modulo>.test.js` com `node:test` e `node:assert/strict`, sem dependências e sem DOM.
7. Comentários e identificadores em inglês. Sem `console.log` no código de produção.

## 2. `src/core/units.js`

```js
mmToPt(mm) -> number
ptToMm(pt) -> number
parseNumber(text) -> { ok: true, value } | { ok: false, code }
formatNumber(value, decimals = config.displayDecimals) -> string
```

- `mmToPt(25.4) === 72`, `ptToMm(72) === 25.4` (tolerância `epsilon`).
- `parseNumber`: aceita `"8,5"`, `"8.5"`, `" 8,5 "`, `"-3,25"`, `"0"`. Rejeita `""`, `"abc"`, `"1,2,3"`, `"8,5.2"`. `"1.000"` (padrão `^\d{1,3}\.\d{3}$`) rejeita com `code: "units.ambiguousNumber"`. Demais inválidos: `code: "units.invalidNumber"`.
- `formatNumber(8.5) === "8,5"`; `formatNumber(8) === "8"`; `formatNumber(8.25, 2) === "8,25"`; sem zeros à direita; arredonda na última casa.

## 3. `src/core/layout.js`

```js
layoutSheet(size, orientation) -> {
  ok: true,
  sheet: { w, h },
  cells: [{ x, y, w, h }],
  dividers: [{ orientation: "vertical" | "horizontal", x1, y1, x2, y2 }],
  grid: { cols, rows },
} | { ok: false, code }
```

- Segue a tabela 3.2 da spec. Dimensões da folha = A4 nominal na orientação derivada.
- Folga de 1 mm dividida 0,5 mm no início e 0,5 mm no fim do eixo aplicável; divisões coincidem com as bordas internas das células (sem vão).
- `dividers` descrevem as linhas de divisão completas, de borda a borda da folha.
- `size`/`orientation` inválidos → `ok: false, code: "layout.invalidSize"`.

Casos de conferência (usar nos testes): A4 portrait `cells.length === 1`, `dividers.length === 0`; A5 portrait → folha 297×210, 2 células `{x:0.5,y:0,w:148,h:210}` e `{x:148.5,…}`, 1 divisor vertical em `x=148.5`; A6 portrait → 4 células, `{x:0,y:0.5,w:105,h:148}`; A6 landscape → folha 297×210, `{x:0.5,y:0,w:148,h:105}`.

## 4. `src/core/strokes.js`

```js
normalizeStroke({ style = "solid", thickness }) -> {
  ok: true,
  style, thickness, cap: "butt" | "round", dash: number[], dashOffset: 0,
} | { ok: false, code }
```

- `dash` = `config.strokePatterns[style]` multiplicado por `thickness * config.strokeScale`.
- `solid` → `dash: []`, `cap: "butt"`. `dashed` → `cap: "butt"`. `dotted` → `dash[0] === 0`, `cap: "round"`. `dashdot` → `cap: "round"`.
- Espessura abaixo de `limits.rulingThickness.min`/acima do máximo → `ok: false, code: "strokes.invalidThickness"`; estilo fora de `enums.rulingStyles` → `"strokes.invalidStyle"`.
- `dashOffset` sempre 0 (a fase começa no início de cada segmento).

## 6. `src/core/migrate.js`

| opacidade | `invalid.opacity` | erro |

## 8. `src/core/cutmarks.js`

```js
cutMarks(layout, margins) -> {
  marks: [{ x1, y1, x2, y2 }],
  warnings: [{ code, params }],
}
```

- `layout` é a saída de `layoutSheet`; `margins` é `{top,right,bottom,left}` em mm.
- Comprimento de cada traço = `min(config.cutMark.length, margem do lado)`; margem 0 → não emite traço e emite aviso `cutmarks.margin.zero` com `params: { side }`.
- Cada traço é perpendicular à divisão? **Não**: o traço corre **sobre a linha de divisão**, da borda da A4 para dentro, na extensão da margem do lado. Ou seja, divisão vertical → traço vertical de `(x, 0)` a `(x, len)` e de `(x, sheet.h - len)` a `(x, sheet.h)`.
- A6: além das extremidades, quatro traços no cruzamento central, um em cada direção, cada um com comprimento `min(cutMark.length, margem do lado oposto)` conforme a tabela 3.4 da spec (`esquerda` usa `right`, `direita` usa `left`, `cima` usa `bottom`, `baixo` usa `top`).
- A4 (sem divisões) → `marks: []`.
- Saída ordenada: extremidades da divisão antes do cruzamento; dentro de cada grupo, na ordem do percurso da divisão.

## 9. `src/core/mask.js`

```js
createMask(widthPx, heightPx) -> { width, height, data: Uint8Array }   // 0 = livre, 1 = bloqueado
maskGet(mask, xPx, yPx) -> 0 | 1                                       // fora dos limites -> 0
rasterizeRotatedRect({ x, y, w, h, rotation }, cellW, cellH, resolution) -> Mask
objectMaskFromAlpha({ width, height, data }, alphaThreshold = config.limits.alphaThreshold) -> Mask  // data: alfa 0..255
fillHoles(mask) -> Mask          // inundação a partir da borda; pixel não alcançado vira bloqueado
dilate(mask, radiusPx) -> Mask   // dilatação euclidiana exata (transformada de distância)
isBlockedMm(mask, xMm, yMm, resolution) -> boolean
buildBlockMask({ objects, alphaMasks, cell, resolution = config.maskResolution }) -> Mask
```

- `rotation` em graus, em torno do centro; retângulo rasterizado em coordenadas locais da célula (0..cellW, 0..cellH).
- `buildBlockMask`: considera só objetos com `visible !== false` (oculto não bloqueia; `locked` bloqueia). `text` → retângulo rotacionado completo. `image` → alfa de `alphaMasks.get(object.imageId)`; sem alfa → retângulo completo. Aplica `fillHoles` e depois `dilate` com raio = `Math.round(preset.ruling.objectDistance * resolution / (2 * config.strokeScale))`? **Não**: raio em pixels = `objectDistance * resolution` (a dilatação avança `objectDistance`, não o dobro). O parâmetro `objectDistance` deve vir do preset; `buildBlockMask` recebe `objectDistance` explícito no objeto de entrada, com padrão 0.
- `dilate` deve ser exato: a borda cresce exatamente `radiusPx` em qualquer direção, sem artefato de máscara quadrada. Tempo para uma célula A4 (840×1188 px) < 200 ms.
- Marca d'água nunca entra em `objects` — não bloqueia.

## 10. `src/core/ruling.js`

```js
rulingArea({ preset, cell }) -> { ok: true, area: { x, y, w, h } } | { ok: false, code: "ruling.areaTooSmall", area }
axisPositions({ length, mode, spacing, count }) -> { ok: true, positions: number[], step } | { ok: false, code }
axisLines(...)      // livre, auxiliar
buildRuling({ preset, cell, blockMask = null, resolution = config.maskResolution }) -> {
  segments: [{ x1, y1, x2, y2 }], dots: [{ cx, cy, r }], warnings: [{ code, params }],
}
```

- `axisPositions`: `count` → `step = length / (n - 1)`, primeira em 0, última em `length`; `spacing` → `n = floor(length / spacing) + 1`, resto dividido igualmente (`primeira = resto / 2`). `spacing > length` → uma posição em `length / 2`.
- `buildRuling` trabalha em coordenadas locais da célula (0..cell.w, 0..cell.h). Cores e espessuras não são aplicadas aqui (a `scene` aplica).
- Corte: amostragem a cada `config.limits.sampleStepMm`; trechos menores que `limits.minSegment` descartados **apenas** em linhas cortadas; linhas sem corte mantidas inteiras; linhas continuam depois do objeto; pontos omitidos quando o disco toca a máscara.
- Ordenação determinística: `segments` por `y1`, depois `x1` (linhas horizontais) e, quando existirem, verticais depois das horizontais ordenadas por `x1`/`y1`; `dots` por `y` e depois `x`.
- Pauta desligada → `{ segments: [], dots: [], warnings: [] }`.

## 11. `src/core/text-layout.js`

```js
layoutText({ text, widthMm, heightMm, style, measure }) -> {
  lines: [{ text, widthMm, words: [{ text, xMm, widthMm }], baselineY, justified }],
  lineHeightMm, contentHeightMm, overflow, hiddenLineCount, unsupportedChars, widthMm, heightMm,
}
```

- `style` = `{ fontId, weight, italic, sizePt, lineHeight, align }`.
- `measure(str, style) -> number` devolve a largura em mm; `style.sizePt` em pontos. É injetável (testes usam fixture). Ausente e com texto → `TypeError`.
- Altura de linha = `ptToMm(sizePt) * lineHeight`. `baselineY` = topo da linha + `ptToMm(sizePt) * 0.8` (constante documentada em `docs/02.01.00-DECISOES.md`).
- `\n` cria parágrafo; vazio produz linha vazia. Quebra por espaço; palavra maior que a largura é quebrada por caractere. `align: "justify"` só justifica linhas que não são a última do parágrafo (última linha `justified: false`).
- `overflow` = alguma linha não cabe em `heightMm`; `hiddenLineCount` = quantidade de linhas descartadas; `lines` contém só as que cabem.
- `unsupportedChars`: caracteres cujo `measure` devolve `0`/`NaN`? Não — cobertura é consultada por `measure(text, style)` retornando `null` para ausência de glifo; nesse caso o caractere entra em `unsupportedChars` e a palavra é medida sem ele. Documentar.

## 12. `src/core/scene.js`

```js
buildScene({ preset, layout, cellIndex = 0, alphaMasks = new Map(), mode = "sheet", measure }) -> {
  widthMm, heightMm, background, primitives, warnings,
}
```

- `mode: "page"` → cena de uma célula, sem marcas de corte; `mode: "sheet"` → cena da A4 montada, com marcas.
- Ordem das primitivas: fundo da folha (`rect` de `page.color`), marca d'água, pauta, objetos na ordem do array, moldura. Cada célula: `clip` com o conteúdo; moldura desenhada acima de tudo e sem `clip`.
- Primitivas: `rect` `{ x, y, w, h, rx, fill, stroke, strokeWidth, strokeStyle }`, `line` `{ x1, y1, x2, y2, stroke, strokeWidth, strokeStyle }`, `dot` `{ cx, cy, r, fill }`, `image` `{ imageId, x, y, w, h, rotation, opacity }`, `text` `{ objectId, x, y, w, h, rotation, fontId, weight, italic, sizePt, color, align, lineHeight, lines, overflow }`, `clip` `{ x, y, w, h, children }`.
- `mode: "page"`: uma célula em 0..cell.w/h, marcas ausentes. `mode: "sheet"`: coordenadas absolutas da A4; cada célula é um `clip`; margens, pauta e objetos têm origem deslocada para a célula.
- Necessita `measure` quando existe texto ou marca d'água de texto; ausente → `TypeError`.
- `warnings` agrega os avisos de `buildRuling` e os de `text-layout` (`text.overflow`).

## 13. `src/core/snap.js`

```js
snapTargets({ preset, layout, cellIndex = 0 }) -> { vertical: number[], horizontal: number[] }
snapValue(value, targets, tolerance) -> { value, hit, target }
snapRect(rect, targets, { tolerance, disabled, mode }) -> { x, y, w, h, guides: [{ axis, position }], hit }

```

- Coordenadas locais da célula. Alvos: bordas e centro da página; bordas das margens; bordas e centro da moldura; limites da área da pauta; posições das linhas da pauta; bordas e centros de outros objetos (`preset.objects`, exceto o próprio).
- Tolerância `config.snap.toleranceMm`; `disabled` devolve a entrada intacta e `guides: []`.
- `snapAngle` arredonda para múltiplos de `config.rotationSnapStepDeg` e normaliza em (−180, 180].
- `guides` sem duplicata e ordenadas.

## 14. `src/store/history.js`

```js
createHistory(initialState, { size = config.history.size } = {}) -> {
  push(state, opts) -> void,   // opts: { tag } — tag igual à do topo agrupa (substitui) em vez de empilhar
  replace(state) -> void,
  undo() -> { ok, state } | { ok: false, code: "history.empty" },
  redo() -> { ok, state } | { ok: false, code: "history.empty" },
  canUndo() -> boolean,
  canRedo() -> boolean,
  state() -> any,
  size() -> number,
  clear(state) -> void,
}
```

- Limite `size` (100 por padrão); ao exceder, descarta o mais antigo.
- `push` com `tag` igual ao do topo (`!== undefined`) substitui o estado do topo: uma interação contínua = um passo.
- Nova ação (`push` sem tag, ou com tag diferente) limpa a pilha de refazer.
- Snapshots por referência: nada de clonagem profunda.
