# Plano — Marco 2: interface, preview e edição

Fonte: `docs/02.00.00-ESPECIFICACOES.md` seções 5, 6, 7.1, 9.1, 10 e 12 (Marco 2), com o núcleo do marco 1 já pronto em `src/core/`. Este plano não altera a spec; em conflito, a spec prevalece.

## 1. Objetivo

Entregar a aplicação utilizável no navegador: painéis de configuração, preview SVG fiel ao PDF, seleção e edição de objetos com snap, camadas, atalhos, desfazer e avisos visíveis. Nada de PDF neste marco (só o Marco 3).

## 2. Pré-requisitos

1. Marco 1 integrado em `main` (commit `55333ee`) com 139 testes verdes.
2. Decisão D11 aplicada: fontes em `.woff` do Fontsource via jsDelivr.
3. `npm run serve`, `npm run shots` e o agente de revisão visual (`docs/01.01.00`) operacionais.

## 4. Regras de execução

- Interface consome o núcleo; nunca o contrário. Nenhum cálculo geométrico em `src/ui/`.
- Zero texto fixo em componente: tudo em `src/strings.pt-BR.js`.
- Zero cor ou medida fixa em CSS: só `var(--token)`.
- Nenhum `innerHTML` com conteúdo do usuário; `textContent` e `createElementNS`.
- Todo erro de entrada gera aviso visível com o código do catálogo §10.4.
- Cada tarefa termina com `npm test` e `npm run lint` verdes e um commit convencional.
- Toda tarefa que altera UI entrega capturas (`npm run shots`) avaliadas pelo agente de revisão visual, com o checklist de `docs/01.01.00` §2.

## 6. Critérios de pronto do marco

1. `npm test` e `npm run lint` verdes.
2. Preview reflete qualquer alteração de configuração em menos de 150 ms para um preset típico (1 imagem, 3 caixas), medido no `console.time` do `main.js`.
3. Todos os atalhos da §5.8 funcionam e o painel `?` os lista.
4. Navegação completa por teclado; contraste AA conferido e registrado em `tests/MANUAL.md`.
5. Mobile: abas e arrasto por toque funcionando em 390 px.
6. Revisão visual aprovada com as capturas de `npm run shots` (checklist V1–V10 de `docs/01.01.00`).
7. Nenhum texto, cor ou número de regra fora de `strings.pt-BR.js`, `tokens.css`, `config.js` e `data/`.

## 7. Riscos

| Risco | Mitigação |
|---|---|
| Divergência entre preview e PDF | Cena única; renderizador SVG consome a mesma `Scene`; teste de primitiva por primitiva |
| Desempenho abaixo de 150 ms | Cena recalculada só na célula visível no modo Página; máscara com cache por objeto |
| Fontes fora do ar no jsDelivr | Aviso `font.loadFailed` e exportação bloqueada; preview cai para fonte local do sistema com aviso |
| Complexidade do arrasto no mobile | Começar por arrasto + alças + campos numéricos (P11), sem pinça |
